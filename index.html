Hello World

This repository is a small C programming project that prints a greeting to the terminal. It is intended as a clear starting point for compiling and running a simple program while practicing basic source control and repository workflows.

Build and run

With a C compiler such as cc, compile and run the program from the repository directory:

cc main.c -o hello-world
./hello-world
